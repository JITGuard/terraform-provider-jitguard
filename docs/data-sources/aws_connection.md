# jitguard_aws_connection (Data Source)

Reads the customer's JIT Guard AWS connection: status, management account,
SSO region and SSO instance ARN.

JIT Guard does not own AWS accounts, OUs, permission sets or groups. Use the
[AWS provider](https://registry.terraform.io/providers/hashicorp/aws/latest/docs)
for those lookups, then feed the IDs/ARNs into `jitguard_approval_rule`.

## Example Usage

```terraform
data "jitguard_aws_connection" "this" {}

output "jitguard_management_account" {
  value = data.jitguard_aws_connection.this.management_account_id
}
```
