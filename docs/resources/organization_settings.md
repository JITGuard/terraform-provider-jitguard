# jitguard_organization_settings (Resource)

Manages the singleton organization settings object: the display name and the
approval expiry window. Permission sets are selected per promotion request and
matched by `jitguard_approval_rule`, not configured here.

This is one resource per customer. Import it with the fixed ID `settings`.
Deleting the resource removes it from Terraform state but leaves the server
settings unchanged; there is no way to delete a customer's settings object.

## Example Usage

```terraform
resource "jitguard_organization_settings" "this" {
  name                  = "Acme Corp"
  approval_expiry_hours = 12
}
```

Omit an attribute to leave the server value unchanged.
