# jitguard_organization_settings (Resource)

Manages the singleton organization settings object: the display name, the
default SSO permission set, and the approval expiry window.

This is one resource per customer. Import it with the fixed ID `settings`.
Deleting the resource removes it from Terraform state but leaves the server
settings unchanged; there is no way to delete a customer's settings object.

## Example Usage

```terraform
resource "jitguard_organization_settings" "this" {
  name                       = "Acme Corp"
  default_permission_set_arn = "arn:aws:sso:::permissionSet/ssoins-1111111111111111/ps-22222222222222222222222222222222"
  approval_expiry_hours      = 12
}
```

Omit an attribute to leave the server value unchanged. Set
`default_permission_set_arn = ""` to clear the default permission set.

## Schema

### Optional

- `approval_expiry_hours` (Number) Hours before an undecided approval request expires (1-720). The server default is 8.
- `default_permission_set_arn` (String) Default SSO permission set ARN. Set to an empty string to clear it.
- `name` (String) Organization display name. Omit to leave the server value unchanged.

### Read-Only

- `id` (String) Singleton identifier, always "settings".

